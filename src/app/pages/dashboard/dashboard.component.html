LeetCode CMS Dashboard

LeetCode CMS Dashboard — это централизованная панель управления для администрирования платформы LeetCode. Данная система позволяет управлять пользователями, создавать и редактировать задачи, а также организовывать теги для удобной классификации контента. Она предназначена для администраторов и модераторов, обеспечивая простой и интуитивный интерфейс для контроля над образовательным контентом и сообществом.

Пользователи

На этой странице можно управлять пользователями системы. Здесь отображается информация о зарегистрированных пользователях, их ролях (Администратор, Интервьюер, Пользователь) и статусах (активен, зарегистрирован, неактивен). Администраторы могут добавлять новых пользователей, изменять роли и удалять аккаунты.

Задачи

Здесь можно управлять задачами платформы. Доступны действия по созданию новых задач, редактированию существующих (название, описание, сложность, теги, материалы) и удалению. Задачи классифицируются по категориям (например, алгоритмы, программирование) и уровням сложности (легко, средне, сложно).
